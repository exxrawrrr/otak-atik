---
name: remote-growth-document-work
description: Locate and inspect supported local documents before deciding whether a separate controlled workflow is needed.
---

1. Resolve the document path when it is unknown.
2. Inspect the document type, structure, metadata, and supported extraction details before making claims.
3. Do not claim that a document was edited unless a supported workflow returns a successful receipt.
4. If a requested change is unsupported, explain the limitation instead of falling back to arbitrary shell or raw file mutation.
