# Attribution

otak-atik is an original orchestration project built around open interoperability concepts.

It is designed to work with ecosystems such as:

- Model Context Protocol-compatible clients and servers;
- Agent Skill / SKILL.md-style instruction modules;
- desktop tool providers;
- Git and GitHub;
- external SaaS connectors.

Third-party implementations retain their respective copyrights, licenses, and trademarks.

Provider adapters in this repository are integration metadata and documentation unless explicitly stated otherwise.

If code or documentation is later adapted from an upstream project, the relevant file or NOTICE entry must identify the source and license.
