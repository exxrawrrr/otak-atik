# ChatGPT client notes

Goal: allow a ChatGPT conversation to use compatible connected tools while keeping otak-atik skills, capability vocabulary, and policy concepts portable.

The exact connector/plugin installation UI belongs to ChatGPT and may change independently of this project.

otak-atik therefore stores provider-neutral operating guidance rather than hard-coding screenshots or fragile UI steps.

For remote desktop use, pair ChatGPT with a compatible remote MCP desktop provider, then use otak-atik skills and policies as the operating layer.
