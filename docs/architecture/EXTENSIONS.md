# Extension model

otak-atik has four extension surfaces.

## Skills

Teach an agent how to perform a class of work.

## Recipes

Compose repeatable multi-step workflows.

## Adapters

Map provider-specific tools to canonical capabilities.

## Client integrations

Explain how an AI client discovers or consumes the operator layer.

The core should remain small enough that contributors can add an integration without editing a giant provider switch statement.
