# Non-Goals

otak-atik V0.x is not trying to become:

- an LLM;
- a model router;
- an AI subscription bypass;
- a remote-desktop GUI;
- a full RPA suite;
- a password manager;
- a general-purpose cloud workflow SaaS;
- a replacement for n8n, Zapier, GitHub, or Desktop Commander;
- a fully autonomous computer-control bot;
- a place to dump every available prompt and skill.

The project integrates existing systems and defines a portable operating contract around them.
