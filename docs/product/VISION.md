# Vision

otak-atik exists to make AI-assisted work on real computers and connected services more structured.

The desired loop is:

```text
understand task
→ discover capabilities
→ load the smallest relevant skill set
→ evaluate policy
→ execute
→ verify
→ record evidence
```

## Product promise

One portable operating layer for AI clients, desktop tools, MCP connectors, local commands, and reusable skills.

## What success looks like

A user can move between compatible AI clients while retaining the same:

- skill library;
- workspace rules;
- capability vocabulary;
- recipes;
- verification expectations.

The AI provider may change. The operator contract should not have to.
